# 首页像素素材目录

首页没有使用任何 AI 生成图片，也没有把一张完整场景图直接铺作 Hero 背景。当前视觉由许可明确的开源像素图层、CSS 光照/地形、SVG 公会纹章和 Framer Motion 动画组合，逐项来源见 `docs/assets-and-licenses.md`。

- `background/`：云层、山林、城堡剪影及入口卡片场景
- `architecture/`：公会建筑裁片与瓦片
- `character/`：NPC 与成员角色素材
- `ui/`：边框、按钮、面板素材
- `icon/`：业务图标素材
- `decoration/`：火把、旗帜、植物等装饰
- `font/`：OFL 许可的中文像素字体及其许可证原文
