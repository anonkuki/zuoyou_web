## 二、未完成或部分完成功能

### 1. PRD 细节补齐

- [ ] **编年史图片字段**：PRD 要求时间线包含“图片”；当前只有年份/时间、标题、内容和发布状态，尚无图片上传、存储与展示。
- [ ] **真实作品收藏系统**：当前“收藏链接”只复制作品链接；尚无用户收藏/取消收藏、收藏数量持久化和个人收藏列表。
- [ ] **成员头像上传**：当前头像使用称呼首字和主题色生成；尚无头像文件上传、裁剪、审核和隐私处理。
- [ ] **密码找回与账号自助恢复**：当前支持激活、登录、管理员停用/恢复，但没有忘记密码、重置令牌和邮件通知流程。
- [ ] **业务通知中心**：招新结果、活动变更、任务指派和作品审核目前依赖页面查询；尚无站内通知、邮件或短信推送。

### 2. 生产交付与运维

- [ ] **Docker 实机验证**：已有 `Dockerfile`、`compose.yml`、持久化卷和健康检查配置，但当前环境未安装 Docker，尚未完成真实容器启动与重启恢复验证。
- [ ] **正式生产部署**：尚未配置真实域名、HTTPS、反向代理、生产密钥、监控告警和线上数据库/上传目录。
- [ ] **备份与恢复**：尚无 SQLite、上传文件和关键配置的自动备份、恢复演练与保留策略。
- [ ] **上传安全增强**：已有类型/大小/权限控制，但尚无病毒扫描、文件内容嗅探、图片重编码和违规内容审核。
- [ ] **持续集成**：仓库暂无 `.github/workflows`；lint、类型检查、测试、构建和 E2E 仍需人工执行。

### 3. 性能与可扩展性

- [ ] **前端进一步分包**：生产构建已成功，但 `three.module` 产物约 734 KB，Vite 仍报告单块超过 500 KB；可通过路由懒加载或动态导入继续优化首屏体积。
- [ ] **大规模并发能力**：当前采用 SQLite、单机本地文件和两秒聊天轮询，适合社团规模与离线演示；若扩展到多实例或高并发，需要数据库、对象存储和实时消息架构升级。
- [ ] **完整可观测性**：当前有业务审计日志和健康检查，但缺少集中式错误追踪、性能指标、日志聚合和告警。

## 四、建议开发优先级

1. **P0：生产可用性**——正式部署参数、HTTPS、备份恢复、监控告警、Docker 实机验证。
2. **P1：PRD 细节**——编年史图片、真实作品收藏、成员头像上传。
3. **P1：账号闭环**——密码找回和站内/邮件通知。
4. **P2：工程效率**——CI 自动门禁、E2E 报告归档。
5. **P2：性能扩展**——Three.js 动态加载、路由分包和高并发架构预案。
