# 首页像素素材目录

阶段 1 首页没有使用任何 AI 生成图片，也没有直接铺设单张背景图。当前视觉由 `src/components/home` 中的原创 SVG、CSS 像素组件和 Framer Motion 动画分层组合。

后续如引入第三方开源素材，必须放入对应子目录，并在 `docs/assets-and-licenses.md` 登记来源、作者、原始链接、许可证和修改说明。

- `background/`：天空、远景、建筑分层素材
- `character/`：NPC 与成员角色素材
- `ui/`：边框、按钮、面板素材
- `icon/`：业务图标素材
- `decoration/`：火把、旗帜、植物等装饰
