## 自动化门禁

- 合约单元测试：角色/状态/分页/校验。
- API 集成测试：401/403/409、生产种子安全、招新激活、容量冲突、签到、活动状态、文件越权/上传/重命名/回收、任务贡献。
- React 测试：首页、表单、登录、文件上传、权限导航等。
- Playwright：4 条跨角色完整业务流程，三种尺寸截图，无游客端控制台错误。
- 静态门禁：ESLint、TypeScript、生产构建，以及代码扫描禁止 `href="#"`。

最终通过数量与时间以交付前最后一次命令输出和 `artifacts/qa/playwright-report` 为准。
