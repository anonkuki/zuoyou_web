## 动画与交互

- SVG 云层与 CSS 云朵分别缓慢移动。
- 独立环境景深层包含暖光束、左右薄雾与十枚错时漂浮光粒，增强空间层次。
- 火把、蜡烛和职业大厅火焰逐帧闪烁。
- 四名角色按不同延迟轻微待机浮动。
- 入口卡悬浮抬升，按钮具有 hover 与 active 位移反馈。
- 页面进入执行淡入动画；减少动画偏好沿用全局 `prefers-reduced-motion` 规则。

## 素材边界

- 未使用 AI 生成图片。
- 未把设计稿或相似背景图直接铺设为背景。
- 首页场景、角色和卡片插画均由项目内 SVG/CSS 原创绘制。
- 中文标题与界面文字使用 OFL 许可的 Fusion Pixel Font，不再依赖普通系统中文字体。

## 产品设计层级

- 首页只有 Hero 标题一个 `primary` 主视觉焦点，建筑招牌与纹章作为支持层。
- 标题、按钮和关键栏目使用像素字体；正文、公告和辅助说明改用高可读中文 UI 字体。
- HUD、入口卡、公告板统一使用深木、古铜、暖金材质变量和一致的高光/投影规则。
- 768px 平板端保持三张核心入口及三栏页脚并列；640px 以下才切换为纵向移动布局。
- 所有首页链接与按钮提供清晰的键盘 `focus-visible` 状态。
