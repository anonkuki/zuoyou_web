# QQ 频道接入说明

## 当前实现

- 官网展示频道号 `pd17345257`，部门页和页脚均可一键复制。
- 当前不读取个人 QQ Cookie，也不模拟登录抓取频道页面。
- B站与公众号内容沿用关联项目的“人工审核快照”方式：定期更新公开链接与元数据，访客打开平台原页面查看。

## 为什么暂不直接爬取

QQ 频道没有仅凭频道号即可匿名读取完整内容的公开 Feed。稳定接入需要在 QQ 开放平台创建机器人，取得 AppID 与 AppSecret，将机器人加入目标频道，并申请相应的频道读取权限。使用个人账号 Cookie 抓取容易失效，也会带来账号与隐私风险，因此不进入生产实现。

## 获得授权后的接入方案

1. 在 QQ 开放平台注册机器人应用，并由频道管理员将机器人加入 `pd17345257`。
2. 仅申请展示所需的最小只读权限。
3. 将凭据放入服务器环境变量，不写入仓库：
   - `QQ_BOT_APP_ID`
   - `QQ_BOT_APP_SECRET`
   - `QQ_CHANNEL_ID`
4. API 服务定时同步已授权的公开消息到本地 SQLite，前台只读取本站缓存。
5. 同步记录来源、发布时间和原消息标识，支持管理员隐藏及重新同步。
