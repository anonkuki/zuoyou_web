# Club-provided brand assets

- `youzi-mascot.png`: the official Sayuu Anime Club mascot portrait supplied by the club. Transparent padding was cropped and the authored pixels were preserved.
- `zuoyou-logo-pixel.png`: the official Sayuu word mark supplied by the club. It was transparently cropped, resized with nearest-neighbour sampling, and reduced to a stepped colour range for pixel-art presentation.

Both files are processed deterministically by `scripts/process-brand-assets.ps1`. No generative or AI image tool is used.
