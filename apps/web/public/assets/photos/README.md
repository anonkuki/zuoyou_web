# 佐佑动漫社网站照片素材索引

请将已确认可以用于网站展示的照片放入对应目录。暂时不要修改现有代码；素材整理完成后，再统一进行裁切、压缩、命名和页面替换。

## 目录说明

- `homepage/`：社团主页、社团合照、社庆、综合活动、首页重点展示照片。
- `departments/cos/`：COS 部活动、返图、妆造、棚拍与漫展照片。
- `departments/tech/`：技术部摄影、后期、直播、设备与技术活动照片。
- `departments/music/`：轻音部排练、演出、乐器与舞台照片。
- `departments/original/`：原创部绘画、手作、创作过程与作品照片。
- `departments/dance/`：舞装部宅舞、排练、服装与舞台照片。
- `departments/publicity-fantasy/`：外宣&幻想研的宣传、推文、企划、放映与主题活动照片。

## 建议数量

- `homepage/`：先放 8–15 张，其中至少有 1 张横向社团主视觉和 3 张精选活动图。
- 每个部门：先放 6–12 张，其中至少有 1 张横向封面图。

## 推荐命名

文件名只使用小写英文、数字和连字符：

```text
cover-01.jpg
featured-01.jpg
gallery-01.jpg
gallery-02.jpg
event-2025-anniversary-01.jpg
```

原始大图可以先直接放进来，不必自行压缩。后续接入页面时会统一生成缩略图和展示图。

## 素材要求

- 普通照片优先使用原始 JPG、JPEG 或 PNG。
- 像素图、透明背景图使用 PNG，不要转成 JPG。
- 请勿放入未获公开展示许可的真人照片。
- 放入素材前建议删除定位信息；后续处理时也会统一清理 EXIF/GPS 元数据。
- 如果某张图片仅限成员查看，请不要放入本目录；公开静态目录中的文件可以被任何访客访问。
